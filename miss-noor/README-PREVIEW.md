# Miss Noor — live preview (playground)

This folder is a **read-only preview build** of the Miss Noor app, published here
so the owner can see the current state of the work in a browser.

- Built from `madnessgate44-debug/Amina` @ `825964c` plus the pending 404-page
  branding fix.
- Static build only. The AI routes in `server.ts` are not present here, so tutor
  chat / speech fall back to their built-in offline copy. Everything else works:
  onboarding, HOME, FEED, LIBRARY, NOUR, save/revisit, My Books.
- The Blind Sniper app itself is untouched; this lives in its own subfolder.
