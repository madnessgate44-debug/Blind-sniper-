# Security policy

Source: GitHub docs, "Adding a security policy to your repository".

## Reporting a vulnerability
Please do not open a public issue for a vulnerability. Use GitHub's private
vulnerability reporting for this repository (Security tab, "Report a vulnerability").
If that option is not enabled, open an issue that says only "security contact
requested" with no details, and the owner will reply with a private channel.

## Scope
Secrets in the repository, workflow permission problems, ways untrusted issue or
pull request text could cause an action, and any path that writes to the private
task store without authentication.

## What not to send
Do not send credentials, tokens or private task data in a report.
