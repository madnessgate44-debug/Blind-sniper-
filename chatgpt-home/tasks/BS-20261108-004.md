## Outcome

Add a native-first, auditable browser execution adapter to Blind Sniper using the pinned open-source `agent-browser` CLI. The runtime remains the owner of task policy, permissions, correlation, evidence and verification. Browser mechanics remain replaceable.

## Baseline findings

- [V] The current integration branch contains a native task planner, guarded lifecycle engine, append-only local ledger, lease operations and mocked GitHub CAS support.
- [V] The runtime explicitly states that it does not execute generic external commands and that browser execution is unavailable without a real host adapter.
- [V] Existing GitHub Actions workflows run on `ubuntu-latest`, but the runtime workflow currently installs Python only; no browser or Node runtime is configured.
- [V] The runner is ephemeral per workflow job. It is suitable for bounded, isolated browser acceptance tests; it is not a persistent authenticated browser host.
- [V] The existing browser skill and MCP registry describe browser policy but do not provide an executable browser adapter.
- [V] Upstream `vercel-labs/agent-browser` package metadata reports version `0.41.2`, Apache-2.0, Node >=22. Upstream documents `agent-browser install --with-deps` on Linux and the CLI command surface.
- [V] The browser tracking issue is #10. Existing E2E PR #9 is open/draft and its head/base have diverged; do not merge or retarget it as part of this task.
- [V] PR #6 and PR #7 are also open/unmerged in a stacked chain. The browser branch is intentionally based on the latest orchestration integration branch, not on an unmerged PR head.

- No user device extension, personal browser profile, cookies, account credentials or private session data.

- No purchases, payments, external message submissions, deletions, account permission changes or credential entry.
- No merge, deployment, secret/permission change or paid provisioning.
- GitHub Actions is an ephemeral test/worker host, not a persistent unattended browser service. Persistent browser hosting remains a separate capability gate.
