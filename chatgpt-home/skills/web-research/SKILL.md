# Web Research Skill

## Purpose
Produce decision-grade research rather than a link dump.

## Prerequisites
Define the question, decision it supports, freshness requirement and scope. Prefer official documentation and primary repositories.

## Permissions
Read-only. Do not sign up, submit forms, purchase, or expose user data.

## Procedure
1. Translate the request into specific research questions.
2. Search primary sources first; inspect README, docs, configuration examples, source code, tests and release history as needed.
3. Distinguish implemented behavior from roadmap, examples and marketing claims.
4. Compare architecture, settings, tools, skills, agents, workflows, permissions, memory and verification.
5. Check licenses before proposing source-code reuse.
6. Extract patterns, incompatibilities, dependencies and operational risks.
7. Convert findings into a capability matrix and implementation backlog.
8. Cite every externally sourced factual claim.

## Evidence
Store source URL, file/section, retrieval date, claim supported and confidence.

## Failure handling
Mark unavailable, stale or unverified information explicitly. Do not infer functionality from a repository name or README badge.

## Completion criteria
The brief answers the decision, separates verified facts from claims, cites primary sources and yields actionable requirements.
