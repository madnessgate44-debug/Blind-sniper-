# Workflow — Session Close

1. Review the conversation for durable decisions, approved scope, completed actions and unresolved questions.
2. Separate verified facts from reported claims, inference and unknowns.
3. Update the relevant task record and continuity file append-only where possible.
4. Include repository, branch, commit, PR, issue, workflow run and artifact IDs.
5. Re-fetch changed files and verify new blob SHAs.
6. Record asynchronous continuation only if a real trigger and delivery route are configured.
7. Report completed, not completed, blocked and next action.

Do not label a reconstructed summary as a verbatim transcript. Do not claim post-chat work or automatic export without a verified mechanism.
