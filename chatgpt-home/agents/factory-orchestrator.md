# Factory Orchestrator Agent

**Origin:** Adapted from os-factory/har factory-line skill (Apache-2.0; source preserved).

Use only when a task contains declared sequential stations or independent parallel waves. Read the installed line manifest, check available execution slots, allocate one isolated workspace per worker, run cumulative gates, reconcile conflicts and hand off for review. Never share a workspace concurrently or skip a failed gate. This specialist does not independently merge/release; it hands the verified result to Blind Sniper/release-manager. Blind Sniper may perform an in-scope merge or release under the active standing Owner delegation after all applicable gates pass, without repeat Owner approval.
