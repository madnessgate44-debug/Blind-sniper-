# Blind Sniper end-to-end simulation

**Purpose:** Exercise the real runtime CLI and local task ledger through a deterministic CI simulation.

## Scenario

1. Create a synthetic task with a stable CI-run correlation ID.
2. Route it through the native workflow, profile, agent and skill registries.
3. Persist REQUESTED, INSPECTING, SPECIFIED, PLANNED and EXECUTING.
4. Perform a bounded local-only action: write a deterministic Markdown artifact.
5. Verify the artifact by SHA-256 and persist VERIFYING.
6. Inject an interruption by replacing the convenience checkpoint with a stale EXECUTING snapshot.
7. Recover the latest state from the append-only ledger and require VERIFYING.
8. Resume through REVIEWING and CLOSED using a deterministic simulation verifier.
9. Validate the ordered event history and upload the ledger, receipt, final state, command outputs and artifact.

## What a PASS proves

- The actual runtime CLI can plan and persist a task.
- Every lifecycle transition is written to the local hash-chained ledger.
- A stale checkpoint can be reconstructed from the ledger after an injected interruption.
- The resumed task can verify its artifact and reach CLOSED under the current metadata gates.
- The receipt is correlated to the exact GitHub commit and workflow run.

## What a PASS does not prove

- No external agent/model is spawned; the execution artifact is generated by this deterministic harness.
- No OpenHands, Forge, browser, provider key, external API or paid service is invoked.
- The reviewer is a deterministic test harness, not a human or independent model reviewer.
- The ledger is local to the GitHub Actions runner. Uploading a 14-day CI artifact is evidence retention, not a GitHub-backed transactional task store.
- This does not prove multi-runner leases, distributed locking, cross-runner recovery, unattended ChatGPT execution or production readiness.

## Run

The Blind Sniper Runtime Registry workflow runs the simulation on matching pushes and pull requests. The receipt and raw evidence are uploaded as a GitHub Actions artifact named blind-sniper-e2e-<run_id>.

The simulation requires GitHub Actions GITHUB_SHA and GITHUB_RUN_ID environment variables and intentionally fails closed outside that environment.
